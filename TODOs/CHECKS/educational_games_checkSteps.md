# Vérification : Jeux Pédagogiques (educational_games)

Ce fichier sert de checklist pour vérifier l'implémentation complète de la spécification.

- [ ] Un accès / bouton "Jeux Pédagogiques" est disponible publiquement (ex: liste des classes).
- [ ] Le contenu des jeux est adapté au niveau de la classe consultée.
- [ ] Pour le niveau CP1 à CE2 : Le contenu est statique et pré-défini.
- [ ] Pour le niveau CM1 et CM2 : Le contenu est généré par IA (basé sur des fichiers PDF du professeur).
- [ ] L'interface UI de la section ludo-éducative fonctionne correctement.
