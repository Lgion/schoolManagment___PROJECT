# Vérification : Rendez-vous et Convocations (appointments_management)

Ce fichier sert de checklist pour vérifier l'implémentation complète de la spécification.

- [ ] Le modèle MongoDB `Appointment` est créé et respecte le schéma défini.
- [ ] Les endpoints d'API (CRUD) pour les rendez-vous sont opérationnels (`/api/appointments`).
- [ ] L'interface utilisateur permet à un parent de demander un RDV à un prof.
- [ ] L'interface utilisateur permet à un prof de convoquer un parent ou demander un RDV.
- [ ] Le système gère les statuts (`PENDING`, `ACCEPTED`, `REJECTED`).
- [ ] Le choix du format (Présentiel ou Visio) est géré.
- [ ] Les notifications / badges pour les rendez-vous en attente sont visibles sur le Dashboard concerné.
