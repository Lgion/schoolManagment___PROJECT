# Vérification : Visio et Communication (communication_and_visio)

Ce fichier sert de checklist pour vérifier l'implémentation complète de la spécification.

- [ ] L'infrastructure Jitsi / Visio est intégrée dans le projet.
- [ ] Le bouton "Lancer une visio" est présent sur la page d'une classe (pour l'enseignant).
- [ ] Les élèves de la classe peuvent rejoindre la salle de visio générée.
- [ ] Le module est relié aux événements (Events) pour pouvoir programmer une visio.
- [ ] Le module est utilisable dans le contexte des rendez-vous Parent ↔ Prof (salle générée automatiquement si le format Visio est accepté).
